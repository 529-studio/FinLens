# S3-01: Local Apple Silicon MLX Qwen2.5-VL-7B 4-Bit Inference Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide complete offline privacy, zero API token cost, and verifiable visual grounding for Mac users by embedding `mlx-vlm` running 4-bit quantized `Qwen2.5-VL-7B-Instruct` under a 6GB unified memory ceiling.

**Architecture:** A dual-layer MLX engine consisting of `ModelManager` (responsible for offline checks, cache directory management, and user-confirmed weight downloading) and `MLXEngine` (responsible for loading 4-bit weights into Apple Silicon Metal memory, enforcing < 6GB ceiling, executing visual inference on rendered page images, and parsing normalized 0-1000 bounding boxes). Wired into `VlmRouter` and FastAPI endpoints.

**Tech Stack:** Python 3.12, MLX (`mlx`, `mlx_vlm`, `mlx_metal`), FastAPI, Pydantic v2, PyMuPDF, Pillow, HuggingFace Hub (`huggingface_hub`).

**Spec:** Issue #10 (`[rag-ml] S3-01: Local Apple Silicon MLX Qwen2.5-VL-7B 4-Bit Inference Engine`), ADR-002 (`Kiến Trúc Suy Luận Dual-Mode`), and AGENTS.md (Rules 1, 11, 12, 13, 14, 15).

## Global Constraints

- Never download model weights automatically without explicit user confirmation (`confirm=True`).
- Target model: 4-bit quantized `mlx-community/Qwen2.5-VL-7B-Instruct-4bit` (estimated ~4.5GB).
- Strict memory ceiling: unified memory consumption must remain < 6GB.
- Strict Path Traversal Defense: all image paths and model directories must validate against `is_path_safe` / `ALLOWED_ROOTS`.
- Bounding box coordinates must be strictly normalized `[ymin, xmin, ymax, xmax]` on a 0-1000 integer scale with `ymax > ymin` and `xmax > xmin`.
- Zero raw emojis in logs, API responses, or code comments (Rule 15).
- All `.env` loading must use explicit relative paths (`Path(__file__).resolve()...`) per `env-and-auth-ops-debugging`.

## Review Focus

1. **Unconfirmed Download Prevention:** Calling download without `confirmed=True` must immediately fail with an explicit permission error before any network request is initiated.
2. **Path Traversal in Model and Image Paths:** Supplying `../../etc/passwd` or outside paths to model loader or inference must trigger a validation error.
3. **Memory Ceiling Enforcement:** The engine must actively measure Metal memory and process RSS; if memory exceeds 6.0GB, emit a structured warning/error.
4. **Offline Resilience:** If network is unavailable or `HF_HUB_OFFLINE=1`, model operations must not hang; offline cached weights or graceful fallback must be returned.
5. **Coordinate Clamping:** Ensure parsed VLM bounding boxes outside [0, 1000] are clamped safely without throwing exceptions or generating negative dimensions.
